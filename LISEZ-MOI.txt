À personnaliser avant publication :
1. Remplacer les trois blocs photo par les vraies photos des véhicules.
2. Remplacer les exemples de véhicules par les annonces réellement disponibles.
3. Ajouter l'URL de la page Facebook dans index.html (lien avec id="facebook-link").
4. Ajouter éventuellement ton logo officiel.

Publication gratuite avec GitHub Pages :
1. Crée un compte sur https://github.com
2. Crée un nouveau dépôt public nommé lampy-autos-gn
3. Téléverse index.html, style.css et script.js à la racine du dépôt.
4. Ouvre Settings > Pages.
5. Dans Build and deployment, choisis Deploy from a branch, puis main et / (root), et sauvegarde.
6. GitHub affichera l'adresse publique de ton site.

Le site est un modèle prêt à personnaliser. Les annonces de démonstration ne représentent pas des véhicules disponibles.
